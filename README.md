# Stack Converter

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/zahedsaifi94/stack-converter)

A minimalist, Apple-inspired web application that takes any public Substack article URL and converts its content into ready-to-paste formats optimized for **LinkedIn Articles** and **X (Twitter) Articles**, complete with AI-generated engagement hooks strictly grounded in the article's text.

## Deployment
- Set environment variable `GEMINI_API_KEY=<your_ai_studio_api_key>`.
- Deploy using the included `Dockerfile` (via Render, Railway, ).
